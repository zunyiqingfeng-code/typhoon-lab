SELF 自研推演说明

SELF（Self-Evolving Learning Forecast）为自研情景推演引擎， 融合三方法外推 120h：持续性外推 + Open-Meteo 引导气流（500hPa）+ 相似路径检索； 强度用 DeMaria-Kaplan MPI + 垂直风切变 + 海温距平修正；概率锥为蒙特卡洛集合， ensemble 为真实 ECMWF/GFS 系综引导风驱动。 SELF 为情景模拟，不构成正式预报。

数据来源：浙江省水利厅台风路径系统 / 中央气象台台风网 / 日本气象厅 / 美国联合台风警报中心 (JTWC)。 本平台用于科研与可视化研究，不构成正式预报依据。
